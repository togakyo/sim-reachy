# おかたづけゲーム

リーチーに声や文字でおねがいして、テーブルの上のボールやつみきを「はこ」や「かご」に片づけてもらうゲームです。

リーチーは、言われたとおりにしか動きません。ボールが2つあるのに「ボールを はこに いれて」と言われると、どちらのボールか分からないので、当てずっぽうで1つ選びます。まちがえたら、子供が言い直す番です。色と名前の両方を言えば伝わることを、遊びながら覚えられるようにしています。

## 遊び方

`./scripts/start.sh`で起動して<http://localhost:8000>を開き、画面右上の「おかたづけ」を押します。リーチーが両手をテーブルの上で構えて、おだいを読み上げます。<http://localhost:8000/#game>で開くと、はじめからゲームの画面になります。

おねがいは、おしゃべりと同じく「こえ」か「もじ」で伝えます。たとえば「あかい ボールを はこに いれて」と言うと、リーチーはボールのほうを見て右手を伸ばし、つかんで、はこまで運びます。

おだいをクリアすると星が出ます。星の数は、何回のおねがいでできたかで決まります。

| 星 | 決まり方 |
| --- | --- |
| 3つ | おだいごとの目安の回数（ほとんどは1回）でできた |
| 2つ | 目安より2回多いところまででできた。または、当てずっぽうで選んだことがあった |
| 1つ | それより多くかかった |

当てずっぽうがたまたま当たったときは、星を2つまでにしています。色と名前をきちんと伝えたときだけ満点になるようにするためです。

### おだい

| おだい | テーブルの上の物 | 覚えてほしいこと |
| --- | --- | --- |
| 1. あかい ボールを はこに いれてもらおう | ボール1つ、つみき1つ | 基本のおねがい |
| 2. きいろい つみきを みせてもらおう | つみき2つ、ボール1つ | 「みせて」と、つみきが2つあるときの言い方 |
| 3. あおい ボールを かごに いれてもらおう | ボール2つ、つみき2つ（青いものが2つ） | 色と名前の両方を言う |
| 4. あおい ものを ぜんぶ はこに いれてもらおう | ボール2つ、つみき2つ | 「ぜんぶ」 |
| 5. ボールは かごに、つみきは はこに かたづけよう | ボール2つ、つみき2つ | 2つのおねがいを1回で言う |

5つクリアすると「じゆう あそび」になり、6つの物で好きなように遊べます。

### リーチーにできること

| 動き | ことばの例 |
| --- | --- |
| 入れる | はこに いれて、かたづけて |
| つかむ | とって、もって |
| 置く | テーブルに おいて |
| はなす | はなして（その場で手をはなす。ボールはころがって、別の場所で止まる） |
| 指さす | あかいのは どれ？、はこは どこ？ |
| 見せる | みせて |

入れ物を言わずに「あおい ボールを いれて」と言うと、リーチーはボールを持ったまま「どこに いれる？ はこ？ かご？」と聞き返します。「かご」とだけ答えれば、そのまま入れます。

## しくみ

```
こえ・もじ → LLM（決まった動作に直す）→ 会話サーバ（どの物か決める）→ Simの首・腕・グリッパー
                                                   └→ ブラウザ（テーブルと物を描く）
```

### LLMは動作を選ぶだけ

LLMには関節を動かさせていません。LLMの仕事は、ことばを「入れる・つかむ・置く・はなす・指さす・見せる」の6つの動作と、色・種類・入れ物の組に直すところまでです。どの物のことか、腕をどう動かすかは[server/game.py](../server/game.py)が決めます。LLMの出力が崩れても、腕がおかしな動きをすることはありません。

### 言っていないことは捨てる

LLMは気をきかせて、子供が言わなかった色を補うことがあります。実際に「ボールを はこに いれて」を「あおい ボールを かごに」と読んだことがありました。これをそのまま使うと、あいまいなおねがいでも正解してしまい、ゲームになりません。

そこで`_ground()`で、LLMの読み取りを子供のことばと照らし合わせています。ことばに出てこない色・種類・入れ物は捨て、LLMが動作を取りちがえたときは、ことばの中の動詞（いれて、みせて、など）と助詞（はこに、はこから）から直します。gemma3:4bで23通りの言い方を試したところ、直したあとはすべて意図どおりの動作になりました。

| | |
| --- | --- |
| ことばの読み取り（LLM） | 中央値2.4秒 |
| 物を1つつかんで入れる動き | 約5秒 |

### Simの中に物はない

Simは`fake:=true`（物理シミュレーションなし）で動かしているので、Simの中にはテーブルも物もありません。Simで動いているのはリーチーの体（首・腕・グリッパー）だけで、物はブラウザが描いています。

リーチーが物に手を伸ばすときの関節角は、[server/table.py](../server/table.py)で求めています。ただし、ブラウザのリーチーは形をデフォルメしたもので、腕の長さが本物とちがいます。本物の逆運動学で角度を出すと、画面の手が物に届きません。そこで、ブラウザのリーチーの寸法で逆運動学を解き、その角度をSimに送っています。ブラウザのリーチーは、Simの腕が動いた結果の関節角で動きます。つかんだ瞬間の手先と物の位置のずれは、実際に測ると0.1cm以内でした。関節の角度は、本物のReachy 2の可動域に収めています。

腕の通り道も確かめています。下ろした腕をそのまま前に出すと、手が天板の下をくぐってしまいます。そこで、いったん肘を曲げて手を胸の前に引き寄せてから構えるなど、天板をくぐらない道だけを通るようにしています。

Simにつながっていないときもゲームは進みます。腕は動かず、物が置き場所のあいだを跳ねて移ります。

### 安全のしくみ

おしゃべりと同じ`_screen()`を、ゲームでも先に通します（[READMEの「安全のしくみ」](../README.md#安全のしくみ)）。遮断したおねがいは、おねがいの回数に数えません。LLMへのプロンプトにも、おしゃべりと同じ「ぜったいのルール」を入れています。

ゲームでリーチーが話すことばは、サーバに書いた決まった文です。LLMが作った文を読み上げるのは、動きのおねがいではなかったとき（「きみの なまえは？」など）の返事だけです。

## 手を入れるとき

| 変えたいもの | 場所 |
| --- | --- |
| おだい | [server/game.py](../server/game.py)の`MISSIONS` |
| 言いかえのことば（「まっか」など） | 同じファイルの`_WORDS`（色・種類・入れ物）と`_VERBS`（動作） |
| 物と入れ物の置き場所 | [server/table.py](../server/table.py)の`SLOTS`と`BINS` |

置き場所の関節角は、サーバの起動時に計算し直します。手が届かない場所があると、起動時にエラーになります。腕が天板をくぐるかどうかは起動時には調べないので、変えたら確認用のスクリプトを流してください。

```bash
.venv/bin/python scripts/check_game.py
```

```
腕の姿勢
  OK  すべての置き場所と入れ物に、可動域の中で手が届く
  OK  手先が物の位置に届く（ずれ 0.1 cm）
  OK  動くとちゅうで天板をくぐらない（78 通りの動き）
  ...
すべて期待どおりです。
```

ブラウザのリーチーの腕の長さを変えたときは、[web/reachy3d.js](../web/reachy3d.js)と[server/table.py](../server/table.py)の`_UPPER`・`_FORE`をそろえてください。
